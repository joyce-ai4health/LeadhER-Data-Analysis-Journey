## Section 1: Getting Started with Excel

### What is Excel and Why Does It Matter?

* Excel is one of the world's most widely used tools for data analysis.
* It is used by professionals across many different industries.
* Excel helps turn **raw data into useful information and decisions** through:

  * Calculations
  * Data analysis
  * Data visualization
* Learning Excel is a valuable skill for a career in data analysis.

### Understanding the Excel Interface

* Excel has different **tabs**, and each tab contains different tools and features.
* The columns in Excel are identified using **letters** (A, B, C, D...).
* The rows are identified using **numbers** (1, 2, 3, 4...).
* The point where a row and column meet is called a **cell**.
* Each cell has a **cell reference/cell notation**.
* Example: **A1** means column A and row 1.

### Workbooks and Worksheets

* Every Excel file is called a **workbook**.
* A workbook can contain multiple **worksheets (sheets)**.
* Different worksheets can be used to organize different sets of information within the same workbook.

### Quick Access Toolbar

* Excel has a **Quick Access Toolbar** that provides quick access to commonly used commands.
* Additional commands can be added by customizing the Quick Access Toolbar.
* The Quick Access Toolbar is located near the top of the Excel window.

---

## Key Takeaways

1. Excel is an important tool for data analysis.
2. Columns are represented by letters.
3. Rows are represented by numbers.
4. The intersection of a row and column is a cell.
5. A cell reference identifies the location of a cell, such as **A1**.
6. An Excel file is called a workbook.
7. A workbook can contain multiple worksheets.
8. The Quick Access Toolbar can be customized.
