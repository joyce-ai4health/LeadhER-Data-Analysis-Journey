## Section 2: Data Entry & Basic Formatting

### What is Data Entry?

Data entry is the process of putting actual information into cells in an Excel spreadsheet.

Examples of data that can be entered include:

- Text
- Numbers
- Dates
- Names
- Salaries
- Employment dates

---

## Entering Data into Cells

Example:

| Cell | Data |
|---|---|
| A1 | Staff Name |
| B1 | Monthly Salary |
| C1 | Date of Employment |

Each piece of information is entered into a specific cell.

---

## Types of Data

Excel can work with different types of data, including:

### Text
Examples:

- Staff Name
- Department
- Job Title

### Numbers
Examples:

- Monthly Salary
- Age
- Quantity

### Dates
Examples:

- Date of Employment
- Date of Birth
- Transaction Date

Excel has a default date format, which can be changed depending on the required format.

---

## Editing Data

Excel allows you to edit information that has already been entered.

Common actions include:

- Editing cells
- Copying data
- Cutting data
- Pasting data
- Deleting or replacing information

### Useful Keyboard Shortcuts

| Action | Shortcut |
|---|---|
| Copy | `Ctrl + C` |
| Cut | `Ctrl + X` |
| Paste | `Ctrl + V` |
| Undo | `Ctrl + Z` |
| Redo | `Ctrl + Y` |

---

## Undo and Redo

### Undo

`Ctrl + Z` reverses the most recent action.

Excel also allows multiple actions to be undone.

You can click the dropdown beside the **Undo** button near the Save icon to view previous actions and select how far back you want to undo.

### Redo

Redo allows you to restore an action that was previously undone.

---

## AutoFill

**AutoFill** allows Excel to automatically fill cells based on a pattern.

For example, if you enter:

```text
January
February
````

Excel can continue the pattern for the following months.

AutoFill can save time when working with repeated or sequential data.

---

## Flash Fill

**Flash Fill** allows Excel to recognize a pattern in your data and automatically complete the remaining entries.

It is useful when transforming or separating data based on a pattern.

Flash Fill can be accessed from:

**Home → Editing → Fill → Flash Fill**

Keyboard shortcut:

`Ctrl + E`

---

## Formatting Data

Formatting helps make data easier to read and understand.

Excel provides different number/data formats, including:

* General
* Number
* Currency
* Accounting
* Date
* Percentage
* Text

To change a data format:

1. Select the column or cells.
2. Go to the **Home** tab.
3. Locate the **Number** section.
4. Select the appropriate format.

---

## Formatting Headers

Headers should be formatted so they are easy to identify.

Formatting options include:

* Background/fill color
* Font color
* Bold text
* Alignment
* Font size

Basic process:

1. Select the header cells.
2. Go to the **Home** tab.
3. Use the **Font** section.
4. Choose the desired background/fill color.
5. Choose the desired text color.

---

## Format Painter

**Format Painter** allows you to copy the formatting of one cell or selection and apply it to another.

### Steps

1. Select the cell or range with the formatting you want.
2. Click **Format Painter**.
3. Select the cell or range where you want to apply the formatting.

### Applying the same formatting to multiple places

Double-click **Format Painter** to keep it active and apply the same formatting to multiple selections.

---

## Cell Borders

Borders can be used to make tables and data ranges easier to read.

### Steps

1. Select the data range.
2. Go to the **Home** tab.
3. Locate the **Font** section.
4. Click the dropdown beside the **Borders** icon.
5. Select the desired border style.

---

## Key Takeaways

1. Data can be entered into individual Excel cells.
2. Excel works with different types of data such as text, numbers, and dates.
3. `Ctrl + Z` is used to undo an action.
4. `Ctrl + C`, `Ctrl + X`, and `Ctrl + V` are used for copying, cutting, and pasting.
5. AutoFill helps complete data based on a pattern.
6. Flash Fill recognizes and applies patterns automatically.
7. Data formats should match the type of information being stored.
8. Headers can be formatted to make tables easier to understand.
9. Format Painter copies formatting from one location to another.
10. Borders help organize and visually separate data.
