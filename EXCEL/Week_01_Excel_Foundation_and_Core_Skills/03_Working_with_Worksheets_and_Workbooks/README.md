## 1. Workbook vs Worksheet

### Workbook

The actual Excel file I am working on is called a **workbook**.

A workbook can contain several worksheets.

### Worksheet

A worksheet is an individual sheet inside an Excel workbook.

For example:

```text
Workbook
│
├── January
├── February
└── March
```

Each worksheet can contain a different dataset or related information.

---

## 2. Inserting, Deleting & Renaming Worksheets

Excel allows me to:

* Insert a new worksheet
* Delete an existing worksheet
* Rename a worksheet

### Best Practice

Each worksheet should contain data or information that matches the name given to the sheet.

For example:

```text
Sales Data
Employee Data
Customer Data
Expenses
```

The worksheet name should make it easy to understand what information is contained in the sheet.

---

## 3. Copying an Existing Worksheet

Excel allows me to create a copy of an existing worksheet.

This is useful when I want to:

* Create a backup
* Reuse an existing worksheet structure
* Work with similar data

---

## 4. Grouping & Ungrouping Worksheets

Multiple worksheets can be grouped together.

### How to Group Worksheets

1. Select the first worksheet.
2. Hold **Ctrl** on the keyboard.
3. Select the other worksheets I want to group.

### Advantage of Grouping Worksheets

When worksheets are grouped, a change made in one grouped worksheet can also be reflected in the other grouped worksheets.

### Important

I need to be careful when working with grouped worksheets because changes can affect **all grouped worksheets**.

### Ungrouping Worksheets

After completing the task, I should ungroup the worksheets to avoid accidentally making changes to all of them.

---

## 5. Hiding & Unhiding Worksheets

Excel allows me to hide worksheets when I do not want them to be visible.

### Hide a Worksheet

1. Right-click the worksheet tab.
2. Select **Hide**.

### Unhide a Worksheet

1. Right-click a visible worksheet tab.
2. Select **Unhide**.
3. Select the worksheet I want to display.

Excel also allows me to hide rows and columns.

---

## 6. Useful Keyboard Shortcuts

### Go to the Last Cell in a Column

```text
Ctrl + Down Arrow
```

This moves to the last filled cell in a particular column.

### Go to the Beginning of the Worksheet

```text
Ctrl + Home
```

This moves to the beginning of the worksheet, normally cell **A1**.

---

## 7. Freeze Rows and Columns

Freezing rows or columns keeps important information visible while scrolling through a large dataset.

### Freeze the Top Row

1. Go to the **View** tab.
2. Select **Freeze Panes**.
3. Select **Freeze Top Row**.

This keeps the top row visible while scrolling down.

### Freeze the First Column

1. Go to the **View** tab.
2. Select **Freeze Panes**.
3. Select **Freeze First Column**.

This keeps the first column visible while scrolling horizontally.

---

## 8. Protecting a Worksheet

A worksheet can be protected so that other users cannot make unwanted changes when the workbook is shared.

### How to Protect a Worksheet

1. Right-click the worksheet tab.
2. Select **Protect Sheet**.
3. Choose the protection options.
4. Add a password if required.

The worksheet can remain visible while users are restricted from changing protected content.

---

## 9. Protecting a Workbook

Workbook protection helps prevent unwanted changes to the structure of the workbook.

For example, it can help control actions such as:

* Adding worksheets
* Deleting worksheets
* Moving worksheets
* Renaming worksheets

### How to Access Workbook Protection

Go to:

```text
File → Info → Protect Workbook
```

---

## 10. Key Takeaways

* An Excel file is called a **workbook**.
* A workbook can contain multiple **worksheets**.
* Worksheets can be inserted, deleted, renamed, and copied.
* Worksheets can be grouped and ungrouped.
* Changes made while worksheets are grouped can affect all grouped worksheets.
* Worksheets can be hidden and unhidden.
* Rows and columns can also be hidden.
* `Ctrl + Down Arrow` can move to the last filled cell in a column.
* `Ctrl + Home` moves to the beginning of the worksheet.
* Freeze Panes keeps important rows or columns visible while scrolling.
* Worksheet protection helps prevent unwanted changes to sheet contents.
* Workbook protection helps protect the workbook's structure.
