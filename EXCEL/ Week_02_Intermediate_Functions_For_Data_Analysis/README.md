## Reflection



Completing Week 2 helped me move beyond the basic Excel skills I learned in Week 1 and become more confident using Excel for data analysis. This week focused on intermediate functions, lookup and reference functions, Excel Tables, data cleaning and text functions, and conditional formatting.

One of the most important things I learned was how to use lookup functions such as `VLOOKUP`, `HLOOKUP`, `INDEX`, `MATCH`, and `XLOOKUP` to retrieve information from different parts of a dataset. Practicing these functions helped me understand how related tables can be connected using a common field and how Excel can be used to find information without manually searching through rows of data.

I also learned how Excel Tables make working with structured data more efficient. I practiced converting data ranges into Tables, using structured references, adding Total Rows, sorting and filtering data, creating calculated columns, and using Slicers. I particularly liked seeing how Tables automatically expand and extend formulas when new records are added.

Data cleaning was another important part of this week. I learned that analysis depends heavily on the quality of the data being used. I practiced using functions such as `TRIM`, `CLEAN`, `LEFT`, `RIGHT`, `MID`, `FIND`, `SEARCH`, `SUBSTITUTE`, `REPLACE`, `VALUE`, `TEXT`, `TEXTJOIN`, `TEXTSPLIT`, `TEXTBEFORE`, and `TEXTAFTER`. I also used Flash Fill to recognize patterns and perform repetitive text transformations more quickly.

Finally, I practiced Conditional Formatting to make patterns and important information easier to identify visually. I worked with Highlight Cells Rules, Top/Bottom Rules, Data Bars, Color Scales, Icon Sets, and formula-based rules. I also learned how to manage, edit, and clear formatting rules.

Overall, Week 2 gave me more practical experience working with data in Excel. I am beginning to see that data analysis is not just about applying formulas, but also about cleaning, organizing, validating, exploring, and presenting data in a way that makes it easier to understand and use for decision-making.
