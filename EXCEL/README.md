# Excel — Weeks 1–3

## Overview

The Excel phase is the first stage of the **LeadHER Foundation Data Analysis Program**. It focuses on building a strong foundation in Excel and developing practical skills for working with data.

## What I'll Learn

* Navigate Excel's interface and core functions
* Clean, organize, and structure raw data
* Build and apply formulas and functions
* Create and use PivotTables
* Create basic charts and visualizations
* Apply Excel to solve real-world data problems

## Weekly Structure

### Week 1 — Excel Foundations & Core Skills

* Getting started with Excel
* Excel interface and navigation
* Data entry and basic formatting
* Working with worksheets and workbooks
* Foundational formulas and functions
* Organizing and managing data

### Week 2 — Data Cleaning & Analysis

* Cleaning raw data
* Identifying and handling errors
* Sorting and filtering data
* Working with formulas and functions
* Preparing data for analysis
* Applying Excel to practical data tasks

### Week 3 — PivotTables, Charts & Practical Applications

* Creating and using PivotTables
* Summarizing and analyzing data
* Creating basic charts
* Choosing appropriate visualizations
* Extracting insights from data
* Applying Excel skills to real-world data problems

## Learning Goal

By the end of Weeks 1–3, I aim to be comfortable using Excel to **enter, clean, organize, analyze, and visualize data**.

> **Learn → Practice → Analyze → Present**
