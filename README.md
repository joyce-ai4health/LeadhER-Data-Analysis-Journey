# LeadHER Foundation Data Analysis Program

## Program Overview

**Program:** LeadHER Foundation Data Analysis Program

**Track:** Data Analysis (Excel + Power BI + SQL) + Leadership Development + Portfolio Website Capstone

**Duration:** 16 Weeks (approximately 4 months)

**Format:** Fully Virtual — Live Sessions, Assignments & Self-Paced Learning

The **LeadHER Foundation Data Analysis Program** is a 16-week learning and development program designed to equip participants with practical **Data Analysis, Business Intelligence, Leadership, and Professional Portfolio Development skills**.

The program combines self-paced learning, live virtual sessions, practical assignments, projects, and a final portfolio website capstone.

---

## Program Structure

The program is divided into **four phases**:

| Phase   | Weeks       | Focus                                               |
| ------- | ----------- | --------------------------------------------------- |
| Phase 1 | Weeks 1–3   | Excel                                               |
| Phase 2 | Weeks 4–9   | Power BI                                            |
| Phase 3 | Weeks 10–12 | SQL                                                 |
| Phase 4 | Weeks 13–16 | Portfolio Website Capstone + Leadership Development |

---

## What I'll Learn

### Phase 1 — Excel | Weeks 1–3

* Navigate Excel's interface and core functions
* Clean, organize, and structure raw data
* Create and use formulas and functions
* Build PivotTables
* Create basic charts and visualizations
* Apply Excel to real-world data problems

### Phase 2 — Power BI | Weeks 4–9

* Navigate the Power BI interface and workflow
* Import and transform data using Power Query
* Clean and prepare datasets for analysis
* Build interactive dashboards and reports
* Use DAX (Data Analysis Expressions) for calculations
* Create effective data visualizations
* Develop data storytelling skills
* Solve real-world business problems using data

### Phase 3 — SQL | Weeks 10–12

* Understand database structures and relationships
* Learn SQL query fundamentals
* Write `SELECT` queries
* Filter data using `WHERE`
* Work with aggregate functions
* Use `GROUP BY`
* Combine data using `JOIN`
* Clean and query real datasets
* Use SQL to answer real-world business questions

### Phase 4 — Portfolio Website Capstone | Weeks 13–14

* Build a personal portfolio website
* Showcase Excel, Power BI, and SQL projects
* Present data projects professionally
* Learn how to communicate project outcomes effectively
* Complete and present a capstone project

### Leadership Development | Weeks 15–16

* Develop core leadership skills through the ELIC Standard
* Improve communication skills
* Build confidence
* Develop workplace readiness
* Strengthen professional and collaborative skills
